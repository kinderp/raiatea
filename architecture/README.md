# Architecture

This area describes current architecture notes only after Raiatea's domain questions and highest risks have enough evidence to justify a durable boundary.

The architecture is expected to be modular, provenance-aware, temporal, source-agnostic, AI-provider-agnostic, and developed through executable vertical slices.

Current architecture notes:

- [`source-plane.md`](source-plane.md) — proposed Source Plane product boundary, simple local runtime, worker-plane evolution and quality model. The decision record is [`ADR-0002`](../adr/0002-source-plane-boundary.md).

Architecture notes must distinguish current accepted behavior, proposed boundaries and future deployment options. They do not promote deferred implementation merely by documenting it.
